HOW TO PLAY

게임 설명과 플레이 방법

게임을 선택한 뒤 항목을 펼치면 목표와 조작법을 확인할 수 있어요.

01CROWNVALEPC 추천＋

건물과 놀이기구를 배치하고 영토·주민·세금을 관리해 작은 땅을 번영하는 왕국으로 키우는 3D 건설 게임입니다.

  1. 오른쪽 건설 메뉴에서 건물을 고릅니다.
  2. 소유한 토지의 원하는 위치를 눌러 배치합니다.
  3. 새 영토를 사고 노동자를 고용해 수입과 인기도를 높입니다.
Q / E카메라 회전F / R각도 조절휠확대·축소Z / X건물 회전O시점 초기화

모바일: 한 손가락 드래그로 지도를 이동하고 두 손가락으로 확대·축소합니다. 메뉴에서 건물을 고른 뒤 땅을 탭해 배치하세요. 화면의 회전·카메라·의뢰 버튼도 사용할 수 있습니다. 복잡한 지도 렌더링으로 프레임이 떨어질 수 있어 PC를 추천합니다.

02포춘 바스티온＋

룰렛으로 타워를 뽑아 설치하고, 강화와 합성으로 끝없이 강해지는 적의 웨이브를 막는 타워 디펜스입니다.

  1. 타워 룰렛을 돌려 인벤토리에 타워를 얻습니다.
  2. 타워를 선택하고 빛나는 설치 칸을 누릅니다.
  3. 웨이브를 시작하고 같은 타워를 강화·합성합니다.
Space웨이브 시작W A S D화면 이동휠확대·축소클릭타워 선택·설치

모바일: 한 손가락으로 지도를 끌고 두 손가락으로 확대·축소합니다. 타워와 설치 칸을 탭한 뒤 웨이브 시작 버튼을 누르세요. 가시 계열 타워는 적이 지나가는 길 위에 놓습니다.

03TETRIS BATTLE＋

블록을 빈틈없이 쌓아 줄을 지우고 AI와 기록을 겨루는 네온 테트리스입니다. 모바일 전용 터치 버튼도 지원합니다.

  1. 1인 플레이를 선택하고 난이도를 정합니다.
  2. 블록을 이동·회전해 가로줄을 완성합니다.
  3. 승리 코인으로 상점 아이템과 테마를 해금합니다.
← / A왼쪽→ / D오른쪽↑ / W회전↓ / S내리기Space즉시 낙하

모바일: 화면의 방향·회전·낙하 버튼을 사용하세요. 이동 버튼을 누른 상태에서 다른 손가락으로 회전할 수 있습니다. GitHub Pages에서는 1인 플레이를 이용할 수 있으며, 실시간 와이파이 대전은 로컬 서버가 필요합니다.

04타이쿤 파크PC 추천＋

빈 부지에 시설을 짓고 손님과 수익을 늘려 나만의 테마파크를 확장하는 경영 게임입니다.

  1. 열린 부지를 누르고 지을 시설을 선택합니다.
  2. 수익을 모아 시설을 업그레이드하고 새 부지를 엽니다.
  3. 연구·마케팅·직원 메뉴를 활용해 운영 효율을 높입니다.
클릭·터치부지와 메뉴 선택W A S D파크 지도 이동

PC 추천: 넓은 관리 패널과 키보드 지도 이동을 사용하는 게임입니다. 휴대폰에서는 화면 일부가 잘릴 수 있어 PC에서 플레이해 주세요.

05체스 게임＋

플레이어가 백을 맡아 AI와 대결하는 클래식 체스입니다. 선택 가능한 이동 칸과 체크 상태를 화면으로 알려줍니다.

  1. 움직일 백색 말을 누릅니다.
  2. 표시된 이동 가능 칸 중 하나를 누르고 AI의 응답을 기다립니다.
  3. 상대 킹을 체크메이트하도록 말을 전개합니다.
클릭·터치말 선택·이동다시하기새 대국 시작
06햇살마을 농장＋

마을을 돌아다니며 작물을 돌보고 주민과 교류하고 미니게임을 즐기는 편안한 픽셀 농장 게임입니다.

  1. 농장을 돌아다니며 작물과 주변 장소를 살펴봅니다.
  2. 화면의 농사·상점·퀘스트 기능으로 하루를 진행합니다.
  3. 미니게임과 활동으로 자원을 모아 농장을 키웁니다.
W A S D이동방향키이동Shift빠르게 이동Space / Enter미니게임 멈추기

모바일: 아래 방향 버튼을 길게 누르거나 지도 빈 곳을 탭해 이동하세요. 빠르게 버튼을 함께 누르면 달립니다. 행동 보기·지도 보기로 화면을 오가고, 낚시터를 탭한 뒤 미니게임의 멈추기 버튼을 사용하세요.

07마왕의 최종 방어선PC 추천＋

마왕을 직접 움직여 왕좌로 몰려오는 용사를 처치하고 영혼으로 무기·방어구·망자를 강화하는 액션 디펜스입니다.

  1. 이동하며 암흑탄과 마왕검으로 용사를 처치합니다.
  2. 떨어진 영혼을 모아 마왕과 소환수를 강화합니다.
  3. 5웨이브마다 휴식 시간에 장비와 망자를 뽑습니다.
W A S D이동클릭 / F암흑탄우클릭 / R마왕검Space파멸의 낫Q지옥불E망자 소환

모바일: 아래 방향 버튼으로 이동하고 맵을 눌러 조준·공격합니다. 암흑탄 버튼을 길게 누르면 연사하고 스킬 아이콘을 탭하면 스킬을 사용합니다. 전투 시야와 장비·건축 관리에는 큰 화면의 PC를 추천합니다.

08NEON TRAILS＋

자동차와 바이크를 골라 넓은 3D 오픈월드를 자유롭게 달리고, 코인·점프·드리프트를 즐기는 드라이빙 게임입니다.

  1. 차고에서 원하는 차량을 선택하고 엔진을 켭니다.
  2. 맵을 달리며 코인과 주행 보상을 모읍니다.
  3. 점프장·트랙·장애물 코스를 찾아 차량을 해금합니다.
W가속S후진A / D조향Shift브레이크Space드리프트Ctrl부스터T윌리V차량 소환드래그카메라

모바일: 아래 조향·가속 버튼을 동시에 누를 수 있습니다. 브레이크·드리프트·윌리·부스터·일시정지 버튼도 지원하며, 맵을 다른 손가락으로 끌면 카메라를 돌립니다. 터치 기기는 기본 낮은 그래픽으로 시작합니다.

09IDLE ISLAND PLANNING＋

작은 섬에 생산시설과 운송망을 세우고 화물을 수출해 무역 도시로 성장시키는 방치형 도시 건설 게임입니다.

  1. START BUILDING을 누른 뒤 왼쪽 시설 건설 메뉴에서 바나나 농장부터 건설합니다.
  2. 시설을 업그레이드해 화물을 생산하고 트럭으로 항구까지 운송합니다.
  3. 화물선이 출항해 얻은 수익으로 도로·크레인·연구를 강화하고 새 지역을 해금합니다.
클릭·터치시설 선택·화물 모으기드래그섬 지도 이동두 손가락지도 확대·축소+ / − / 휠지도 확대·축소왼쪽 메뉴시설 건설·해외 무역·연구소⚙ 설정가이드·게임 설정

모바일에서는 한 손가락으로 지도를 끌고 두 손가락을 벌려 확대합니다. 확대 후 한 손가락을 떼어도 계속 이동할 수 있습니다. 진행 상황은 현재 브라우저에 자동 저장됩니다.

10SPIN OUT＋

빨간색 YOU 공으로 20명의 AI와 함께 회전 막대를 피하고, 코인을 모아 능력을 강화하는 물리 서바이벌 게임입니다. 경기장 밖으로 떨어지면 보호막과 함께 다시 등장합니다.

  1. 게임 시작을 누르고 빨간색 YOU 공을 확인합니다.
  2. 이동과 점프로 회전 막대를 피하고 10초마다 나타나는 코인을 모읍니다.
  3. 상점에서 이동 속도·점프 재충전·리스폰 보호막·자석을 강화합니다.
WASD / 방향키공 이동마우스클릭·드래그 방향 이동터치 드래그누르고 있는 방향으로 이동Space / ↑ 점프점프B / 상점일시정지하고 강화 구매다시 시작코인·강화를 초기화하고 새 게임

모바일은 세로 화면을 권장합니다. 한 손으로 화면을 누른 채 이동하고 다른 손으로 하단 점프 버튼을 누르세요. 손을 떼면 터치 조작이 해제됩니다.

11코어 블레이드PC 추천＋

코어 블레이드 또는 아카이브 센티널을 선택해 사방에서 몰려오는 블록 적을 쓰러뜨리는 3D 아레나 액션 게임입니다.

  1. 쌍검 균형형 코어 블레이드와 사격형 아카이브 센티널 중 한 유닛을 선택합니다.
  2. 아레나를 이동하며 카메라 방향을 조절하고 적과 거리를 잡습니다.
  3. 검격과 사격으로 웨이브를 버티며 쓰러뜨린 적 수를 늘립니다.
W A S D이동Q / E카메라 회전Shift질주Space / 클릭공격C캐릭터 변경R다시 시작

PC 추천: 현재 터치 화면에서는 공격과 메뉴 선택만 가능하고 이동·카메라 회전에는 키보드가 필요합니다. PC에서 키보드와 마우스로 플레이해 주세요.

12키캡 클릭커＋

  1. 화면 가운데 키캡을 누릅니다.
  2. 키캡을 놓고 다시 누르며 반응과 소리를 즐깁니다.
