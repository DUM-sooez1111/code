**게임 모음 페이지:** https://dum-sooez1111.github.io/code/

## 수록 게임

- CROWNVALE — 왕국 건설
- 포춘 바스티온
- TETRIS BATTLE
- 타이쿤 파크
- 체스 게임
- 햇살마을 농장
- 마왕의 최종 방어선
- NEON TRAILS
- IDLE ISLAND PLANNING — 방치형 섬 도시 건설
- SPIN OUT — 회전 물리 서바이벌
- 코어 블레이드 — 3D 아레나 액션

각 게임 카드의 화살표 버튼을 누르면 해당 게임이 새 탭에서 열립니다.

게임은 **전략·경영**, **퍼즐·보드**, **액션**, **드라이빙** 카테고리로 골라 볼 수 있습니다.

모바일 조작법은 페이지의 게임 가이드에서 확인할 수 있습니다. 큰 화면이나 키보드가 편리한 게임에는 작은 **PC 추천** 표시가 있습니다.
